# 文档提交规范

:::info[提示]

文档仓库地址：[Github](https://github.com/Round-Studio/Docs)

:::

## 😎 缩进规范

| 功能 | 说明 | 例子 |
|------|------|------|
| 🔥 普通缩进 | 以 2 个空格为一个单位 | - |
| 🐱 字符缩进 | 数字，英文 与 中文之间用 1 个空格保持间距 | 有 1 个 数字， A 种 类型 |
| 🎉 类型缩进 | 不同类型之间的文字直接使用 1 个空格保持间距 | 有 1 个 数字， A 种 类型 |

## ✨ 题头规范

题头就是要醒目，不醒目的能叫题头吗  

| 功能 | 说明 | 样式 |
|------|------|------|
| 👊 大标题 | 单页文档总标题 | 以 # 开头 |
| 👿 二级标题 | 单页文档中的不同子目录 | 以 ## 开头 |
| 🌐 子标题 | 二级标题及以下 | 以此类推 |
