# 开始使用

## 简介
OverrideLauncher.Core 是一个用 C#/.NET 8 编写的高性能 Minecraft 启动器核心库，支持快速安装和启动各种版本的 Minecraft，包括原版、Forge、Fabric、LiteLoader 等。

## 特性
- ⚡ 高速下载和多线程支持
- 🎯 支持多种安装类型：原版、Forge、Fabric、LiteLoader
- 🔧 完整的账户系统支持（离线/在线）
- 📦 自动依赖管理和库下载
- 🌐 多镜像源支持
- 🚀 轻量级且易于集成

## 安装

### NuGet 包管理器
```bash
dotnet add package OverrideLauncher.Core
```

### .csproj 引用
```xml
<PackageReference Include="OverrideLauncher.Core" Version="*" />
```
