# 复合安装器

复合安装器 意为 多种安装器的组合，用于安装多种不同的客户端，例如 Vanilla、Fabric、LiteLoader 等

## 安装器列表

- Vanilla 安装器
- Fabric 安装器
- Forge 安装器
- LiteLoader 安装器

## 示例

```c
using OverrideLauncher.Core.Classes.Install.Installer;

var collectionInstaller = new InstallerCollection(new InstallerCollectionEntry()
{
    VanillaManifest = await InstallHelper.TryingFindVersion("1.20.1"),
    FabricVersion = (await InstallHelper.GetVersionFabricManifest("1.20.1")).First(),
    FabricApiVersion = (await InstallHelper.TryGetFabricApiVersions("1.20.1")).First()
});

await collectionInstaller.Install(new ClientRootInfo()
{
    ClientName = "1.20.1-fabric-collection",
    ClientRootPath = installPath
});
```

## 属性参数

```c
public class InstallerCollectionEntry
{
    public ManifestMojang.ManifestVersion VanillaManifest { get; set; } = null;     // 原版版本
    public FabricLoaderVersion FabricVersion { get; set; } = null;                  // Fabric 版本
    public FabricApiEntry.FabricApiVersion FabricApiVersion { get; set; } = null;   // Fabric Api 版本
    public string ForgeVersion { get; set; } = String.Empty;                        // Forge 版本
    public LiteLoaderManifest.VersionData LiteLoaderVersion { get; set; } = null;   // LiteLoader 版本
}
```

## 获取

| 安装器 | 获取方法 |
| ------ | -------- |
| Vanilla 安装器 | `InstallHelper.TryingFindVersion("1.20.1")` |
| Fabric 安装器 | `InstallHelper.GetVersionFabricManifest("1.20.1")` |
| Forge 安装器 | `InstallHelper.TryGetInstallForgeMeta("1.20.1")` |
| LiteLoader 安装器 | `InstallHelper.TryGetInstallLiteLoaderMeta("1.20.1")` |
