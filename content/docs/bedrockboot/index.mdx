# BedrockBoot 介绍

这是一款为 Windos 开发的 Minecraft Bedrock 启动器  
采用 [Avalonia](https://avaloniaui.net) 框架搭建现代化 UI  

# 如何下载？

您可以前往我们的 [Github 仓库](https://github.com/Round-Studio/BedrockBoot) 进行下载  
也可以通过我们的 [BedrockBoot 官网](https://roundstudio.top/bedrockboot) 进行下载  

# 先决条件

需要安装 dotnet 10.0 为运行时，否则将无法运行.orz
