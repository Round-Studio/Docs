# 遇到崩溃了，我该怎么办？

当前软件虽然处于正式发布阶段，但还存在大量 Bug  
每当软件出现崩溃时，会显示一个崩溃窗口

![Image](/assets/bedrockboot/01.png)  

此时您可以前往 [Github Issues](https://github.com/Round-Studio/BedrockBoot/issues) 进行反馈  
也可以通过 [QQ Group 245839607](https://qm.qq.com/q/Heo6PaUcY6) 进行反馈  
但显然我们更推荐前者  

### 我需要如何提交有用的反馈信息？

首先，错误信息是肯定要的。  
其次，您可以附上当时的日志。  
当然最好，如果您可以再次复现的话，可以加上复现视频...  
日志地址：`%APPDATA%\RoundStudio\BedrockBoot2\BedrockBoot.Log`

### 资源包触发的崩溃？

你需要提交相关的 `资源包/行为包` 样本，以便于开发人员进行调试。
