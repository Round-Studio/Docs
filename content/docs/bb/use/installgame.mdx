# 先决条件

在进行安装游戏前，需要您先创建一个游戏目录，用来存储游戏实例及其它数据。  

## 导入目录

前往实例管理页面，点击左侧卡片最底部的 `+` 符号按钮  

![Image](/assets/bb/02.png)  

点击后，会出现一个对话框  

![Image](/assets/bb/03.png)  

根据您本机的情况导入一个目录，然后点击确定。

## 导入其他启动器的目录

不管是什么启动器，都需要您点击 `导入其他启动器配置` 按钮，进入以下页面  

![Image](/assets/bb/04.png)  

### Levilauncher

点击 `Levilauncher` 选项，启动器会自行导入并关闭该抽屉  
再次刷新实例管理页面，即可显示您先前在 Levilauncher 中安装的实例。

### BMCBL 

点击 `BMCBL` 选项，启动器会打开一个文件选择对话框，用户选择 BMCBL.exe 本体后启动器会自行导入并关闭该抽屉  
再次刷新实例管理页面，即可显示您先前在 BMCBL 中安装的实例。

# 开始安装

现在，终于可以开始安装游戏了...  
点击下载页面，在上方搜索您需要的游戏版本 或 点击 `版本列表` 按钮  

![Image](/assets/bb/05.png)  

在您搜索到一个您需要的游戏版本后，点击它，进入一个抽屉页面   

![Image](/assets/bb/06.png)  

- *如果在先前您已经安装了相同的版本，在抽屉页面左下角会有一个 `使用安装包缓存` 的勾选框。*
- *`使用安装包缓存` 即使用先前已下载过的安装包进行安装，跳过重新下载游戏的步骤，以节省等待时间。*

填写好相应的信息，即可点击 `开始安装` 进行安装。

# 如何查看安装进度

点击进入 `任务中心` 页面以查看启动器所有正在执行的后台任务
