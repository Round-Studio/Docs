欢迎使用 BedrockBoot v2！在这个版本，我们使用了 Avalonia 跨平台框架进行了重构，使其可以在不同平台上表现出相同效果！

由于 BedrockBoot v2 在 2026.4.11 推出了 Linux 平台的可执行文件，所以在 Windows 与 Linux 中会有些许差异

# 下载

您可以前往我们的官方网站进行下载，也可以前往 BedrockBoot Github 仓库进行 Release 的下载

[BedrockBoot 官方网站](https://roundstudio.top/bedrockboot)  
[BedrockBoot 开源仓库](https://github.com/Round-Studio/BedrockBoot)

假如您在使用中遇到了困难，可以先参阅 [常见问题](/docs/product/bb/commonQuestion)。  
如果无法解决，请参阅 [技术反馈](/docs/product/bb/feedback) 进行反馈。

## 更新渠道

如果您想要体验最新的功能（常常伴有极大的不稳定性），请参阅 [软件更新](/docs/product/bb/use/softUpdate)
