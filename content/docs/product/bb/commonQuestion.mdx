# 运行相关

### 提示需要安装运行时

- 情况 A.
    - 症状：在初次运行 BedrockBoot 时，弹出以下窗口：  

    ![Image](/assets/bb/07.png)

    - 原因：这是未安装所需运行时导致的错误。 
    - 解决方案：需要 [下载 dotNET 10.0 | Microsoft](https://aka.ms/dotnet-core-applaunch?missing_runtime=true&arch=x64&rid=win-x64&os=win10&apphost_version=10.0.2&gui=true)

- 情况 B.
    - 症状：已安装 dotNET 运行时，但启动启动器弹出需要安装 VC 2015-2022 对话框  

    ![Image](/assets/bb/09.png)

    - 原因：*如图所示.jpg*
    - 解决方案：单机 `OK` 或 `确定` 以启动启动器的 VC 自动安装程序

    ![Image](/assets/bb/10.png)

    等待其自动安装完毕即可

    A. 少数用户在启动启动器时会无法显示启动器界面，多数用户会无法启动游戏

# 游戏相关

### 提示本机已安装打包版本……

- 症状：提示本用户或其他用户已安装该应用的打包版本，无法安装未打包版本
- 原因：本机已在 Microsoft Store 中安装其打包版本
- 解决方案：前往 Microsoft Store 中删除原有的 Minecraft Bedrock （**请自行备份其重要数据**）

### ~~提示无法注册包……~~（最新版已修复）

- 症状：启动游戏时提示无法注册包…… 或 使用其他的第三方 Minecraft Bedrock 启动器时出现此错误
- 原因：旧版 BedrockBoot 的版本隔离系统将文件夹占用
- 解决方案：手动删除 `%APPDATA%/../Local/Packages` 下有关 Minecraft 的文件夹（文件夹通常是 `Microsoft.MinecraftUWP_8wekyb3d8bbwe`）

### 提示 `需要有 Windows 开发者许可证或启用旁加载的系统` 时

- 症状：启动或安装游戏时启动器出现带有 `需要有 Windows 开发者许可证或启用旁加载的系统` 字样的弹窗
- 原因：系统未开启开发者模式
- 解决方案：前往 `系统设置` 中，搜索 `开发者` 字样，找到 `开发者模式` 并启用

### 启动 UWP 类型实例时无法锁定鼠标

- 症状：启动 UWP 类型的游戏时，鼠标会飘出游戏窗口
- 原因：Mojang 的问题
- 解决方案：等我们开发鼠标锁 ~~（还没开发）~~

### 启动 GDK 类型的游戏时任务中心有任务但很快就没了

- 症状：启动 GDK 类型的游戏时，任务中心会有任务，任务管理器有 `Minecraft.Windows.exe` 的后台进程，但均无游戏窗口显示
- 原因：未安装 `Xbox Service` 游戏服务
- 解决方案：前往 `Microsoft Store` 搜索 `Xbox Service` 或 `游戏服务` 以安装需要的组件

### 安装 UWP 游戏时提示需要安装相关框架

- 症状：启动或安装 UWP 类型的游戏时，启动器提示需要安装相关游戏框架
- 原因：本机未安装 `Minecraft UWP` 游戏所需要的框架
- 解决方案：前往 [Minecraft UWP 框架下载 | MCAPPX.COM](https://www.mcappx.com/download/mc-framework/)

### 安装游戏版本 `1.18.x` ~ `1.19.x` 之间的版本遇到无法启动

- 症状：已下载此版本，启动后显示 `Mojang` 徽标后闪退
- 原因：未知
- 解决方案：目前此类 bug 尚无法解决，初步判定是 `Mojang` 的问题

# 下载

### 在下载页面无法显示游戏列表

- 症状：在下载页面但是无法显示可下载的游戏版本
- 原因：你网炸了
- 解决方案 A：检查是否有使用 vpn 等工具，如果有，将其关闭
- 解决方案 B：前往启动器 设置 > 下载 > 列表源，将其切换至一个你可以使用的列表源
